# English

## Divoom PC Monitor v1.3.2

- TimesFrame Hardware **510, 511 and 512** now automatically select PC monitoring face **1631** before sending data.
- These three models use `http://DEVICE_IP:9000/divoom_api` with `ScreenList[0].LcdId` and six metric strings. Other models retain their existing clock and endpoint rules. Five-screen controls remain exclusive to 400/402.
- Corrects the earlier advice about clock 1018: the physical TimesFrame identifies 1631 as “Computer monitoring”. On Hardware 511, selecting 1631 and five subsequent updates all returned success. The user confirmed the face opens but values do not refresh on existing firmware. Its old 1018 controller lookup has been corrected in the supplied firmware source; deploying and verifying that firmware is separate from this desktop update.
- Local validation: 186 Windows checks, 76 Mac/shared checks, and five desktop checks passed. CI additionally tests 510/511/512 through the real backend bridge against a loopback device. Hardware 510/512 have not yet been tested physically.

# 简体中文

## Divoom PC 硬件监控 v1.3.2

- TimesFrame **510、511、512** 加入自动切换白名单，连接时先选择 PC 监控表盘 **1631**，再发送数据。
- 这三个型号统一使用 `9000/divoom_api`，发送 `ScreenList[0].LcdId` 和六项指标字符串。其它型号的表盘与端口规则保持不变；五屏选项仍仅在 400/402 显示。
- 更正此前关于 1018 的建议：TimesFrame 实机确认 1631 名称为“电脑监测”。511 实测选表及随后 5 次更新均返回成功，用户确认已显示表盘但旧固件数值不刷新。提供的固件源码已修正按 1018 查找控制器的问题；该固件的更新与实机验证独立于此次桌面更新。
- 本地通过 Windows 186 项、Mac 共享逻辑及界面 76 项、桌面 5 项检查；CI 通过真实后台桥接向回环模拟设备测试 510/511/512。510/512 尚未做实机验收。

Windows 提供安装包和免安装 ZIP，完整解压后运行 **DivoomPCMonitor.exe**。Mac 分别提供 Apple 芯片和 Intel 芯片 DMG 测试包，尚未完成 Developer ID 签名、公证及用户实机验收。附 SHA-256 校验文件。
