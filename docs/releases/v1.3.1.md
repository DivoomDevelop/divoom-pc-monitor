# English

## Divoom PC Monitor v1.3.1

- Fixes clipped error messages in both the Tauri interface and legacy Windows interface. The bottom status area now wraps multiple lines, scrolls, and supports selecting and copying the full message.
- Preserves complete device error responses instead of truncating them to 300 characters; LocalToken and DeviceToken values remain redacted.
- Fixes Hardware 511 PC data: uses `ScreenList[0].LcdId` and six strings at `http://DEVICE_IP:9000/divoom_api`, retaining the existing clock-selection whitelist. No clock-switch command is sent to 511.
- Validated against a physical 511: five consecutive successful updates over ten seconds. Open the PC monitoring face manually on the device; a successful response does not prove an inactive face was displayed.

# 简体中文

## Divoom PC 硬件监控 v1.3.1

- 修复 Tauri 和旧版 Windows 界面底部错误显示不全：支持多行换行、滚动查看、全选与复制。
- 设备返回错误不再截断到 300 字符，LocalToken、DeviceToken 继续脱敏。
- 修复 Hardware 511 的 PC 数据格式：在 `9000/divoom_api` 发送 `ScreenList[0].LcdId` 和六项字符串；保留原有表盘切换白名单，不向 511 发送切换表盘命令。
- 511 实机测试 10 秒内连续成功发送 5 次。请手动打开设备上的 PC 监控表盘；设备返回成功不等于已切到该页面。

Windows 提供安装版和免安装 ZIP，完整解压后运行 **DivoomPCMonitor.exe**。Mac 分别提供 Apple 芯片和 Intel 芯片 DMG 测试包；尚未完成 Developer ID 签名、公证和用户实机验收。发布包附带 SHA-256 校验文件。
