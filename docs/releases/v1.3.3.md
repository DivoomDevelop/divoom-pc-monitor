# English

## Divoom PC Monitor v1.3.3

- Rebuilds the Tauri desktop application and installers with the latest bilingual documentation and validation notes. Hardware collection and device communication behavior are unchanged from v1.3.2.
- TimesFrame Hardware **510/511/512** automatically select PC monitoring face **1631**, then send six metrics using `ScreenList/LcdId` at `9000/divoom_api`. Other clock and endpoint rules are preserved.
- Existing TimesFrame firmware may open the face without refreshing values because its PC controller lookup uses the old ID 1018. The supplied device source was corrected separately; this desktop package does not install that firmware, and the device-side fix has not been verified on hardware.

# 简体中文

## Divoom PC 硬件监控 v1.3.3

- 重新构建 Tauri 桌面程序与安装包，随包更新中英文说明及验证记录。采集、设备通信和界面功能沿用 v1.3.2。
- TimesFrame **510/511/512** 连接时自动选择 PC 监控表盘 **1631**，随后向 `9000/divoom_api` 发送 `ScreenList/LcdId` 六项指标；其它表盘与端口规则保持不变。
- 旧 TimesFrame 固件按 1018 查找 PC 控制器，可能出现表盘打开但数值不刷新。设备源码已单独修正；本次桌面安装包不安装设备固件，设备修复仍待上机验证。

Windows 提供安装包和免安装 ZIP，完整解压后运行 **DivoomPCMonitor.exe**。Mac 分别提供 Apple 芯片和 Intel 芯片 DMG 测试包，尚未完成 Developer ID 签名、公证及用户实机验收。附 SHA-256 校验文件。
