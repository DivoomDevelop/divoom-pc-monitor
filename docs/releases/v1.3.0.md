# English

## Divoom PC Monitor v1.3.0 — Tauri

- Migrates the Windows and Mac interface and packaging to Tauri 2, retaining the C# hardware collection and Divoom transport backend.
- Adds a persistent blue notice: **Only devices on the same local network as this computer can be connected.** It is localized into all 19 supported languages.
- Keeps connection settings scrollable while the notice and send button remain visible. Preserves 400/402-only LCD options, endpoint rules, clock whitelist and session-only LocalToken.
- Includes Chinese and English guides, runtimes and third-party licenses.

### Downloads

| Platform | Package |
| --- | --- |
| Windows 10/11 x64 installer | `DivoomPCMonitor-win-x64-v1.3.0-setup.exe` |
| Windows 10/11 x64 portable | `DivoomPCMonitor-win-x64-v1.3.0.zip` |
| macOS 14+ Apple Silicon | `DivoomPCMonitor-mac-arm64-v1.3.0.dmg` |
| macOS 14+ Intel | `DivoomPCMonitor-mac-x64-v1.3.0.dmg` |

For the portable ZIP, extract the complete directory and open **DivoomPCMonitor.exe**. For Mac, open the DMG and drag DivoomPCMonitor.app into Applications. Packages include the .NET runtime. Windows requires WebView2; the installer handles a missing runtime.

Mac packages use ad-hoc signatures and have not completed Developer ID signing, notarization or physical-user-Mac acceptance. Gatekeeper may block them. The same-LAN notice is guidance, not an automatic network validation result.

The automated build runs native backend/desktop checks and verifies uploaded SHA-256 digests before publishing. See [validation scope](https://github.com/DivoomDevelop/divoom-pc-monitor/blob/main/docs/VALIDATION.md) and [Tauri build guide](https://github.com/DivoomDevelop/divoom-pc-monitor/blob/main/docs/TAURI.md). Use the checksum file to verify downloads.

# 简体中文

## Divoom PC 硬件监控 v1.3.0 — Tauri

- Windows、Mac 的界面和默认打包方式迁移到 Tauri 2，保留 C# 硬件采集与 Divoom 设备通信后台。
- 设备连接区增加常驻浅蓝提示：**仅支持连接与本电脑处于同一局域网的设备。** 支持全部 19 种语言。
- 提示和发送按钮固定显示，设置内容可单独滚动；保留 400/402 专用 LCD 选项、原有端口规则、表盘白名单和仅本次运行保存的 LocalToken。
- 包含中英文说明、运行时和相关第三方许可证。

### 下载和使用

Windows 提供 `DivoomPCMonitor-win-x64-v1.3.0-setup.exe` 安装包及免安装 ZIP。ZIP 完整解压后运行 **DivoomPCMonitor.exe**，保留 `monitor` 后台目录。Mac 分别下载 Apple 芯片或 Intel 芯片 DMG，将 DivoomPCMonitor.app 拖到“应用程序”。不需要另装 .NET，Windows 界面需要 WebView2，安装程序会处理缺少的运行时。

Mac 测试包使用 ad-hoc 签名，尚未完成 Developer ID 签名、公证及用户真实 Mac 验收，可能被 Gatekeeper 阻止。同局域网提示是连接前的说明，不代表已自动验证当前网络可达。

自动构建会运行后台与桌面检查，并核对上传文件的 SHA-256 后统一公开所有平台。详细验证范围和构建说明见上方链接。
